# Gentle 1999 Academic Homepage

This repository contains a bilingual Quarto-based personal academic homepage designed for GitHub Pages. Python scripts generate external metadata, while Quarto pages focus on presentation.

## Requirements

- Quarto
- uv
- make
- Typst, or a Quarto installation with bundled Typst support

## Local Workflow

```bash
make install
make configure
make update
make render
make preview
```

The default interface is English at `/`. Chinese pages live under `/zh/`. Keep language-specific narrative content in `.qmd` files. External metadata outputs such as `data/repos.json`, `data/publications.json`, `data/publication_images.json`, `data/publication_pdfs.json`, `_generated/`, `assets/publications/generated/`, `publications.bib`, `cv/publications.typ`, and `assets/miao-jiong-tang-cv.pdf` are regenerated by `make update` or `make build-cv` and should not be edited by hand. Use `make update-publication-images` when you only want to refresh publication images, and `make update-publication-pdfs` when you only want to refresh publication PDF links. Keep manually curated corrections such as `data/publication_overrides.json` under version control.

## Publication PDFs

Publication pages can show a direct `PDF` download link when a PDF is available. Publication PDFs are local or CI artifacts by default and are ignored by Git. All PDFs, whether manually supplied or automatically downloaded, live under a DOI slug directory:

The preferred filename is `paper.pdf`, but any `.pdf` file in the DOI directory will be detected:

```text
assets/publications/pdfs/10-1038-s42256-025-01098-4/paper.pdf
```

Then run:

```bash
make update-publication-pdfs
make render
```

Automatic PDF discovery is enabled by default and only uses directly downloadable public candidates. When available, set `UNPAYWALL_EMAIL` or `CROSSREF_EMAIL` to improve open-access PDF discovery.

## CV PDF

The source CV lives in `cv/main.typ` with shared styling in `cv/theme.typ`. Build the PDF with:

```bash
make build-cv
```

`scripts/generate_cv_publications.py` writes `cv/publications.typ` from `data/publications.json`, and `scripts/build_cv.py` compiles the English and Chinese Typst CV PDFs. `make update-cv` refreshes publication metadata before compiling the CV.

## Configuration

Common settings are read from environment variables:

- `GITHUB_USERNAME`: GitHub account used by `scripts/update_github_repos.py`
- `PROFILE_NAME`: display name used in the homepage hero, navbar title, browser title, and footer
- `PROFILE_NAME_ZH`: Chinese display name; defaults to `PROFILE_NAME`
- `PROFILE_ALIASES`, `PROFILE_ALIASES_ZH`: optional publication name variants shown under the profile title
- `SITE_TITLE`: optional site title override; defaults to `PROFILE_NAME`
- `PROFILE_EMAIL`, `PROFILE_ROLE`, `PROFILE_AFFILIATION`, `PROFILE_LOCATION`: English profile metadata
- `PROFILE_ROLE_ZH`, `PROFILE_AFFILIATION_ZH`, `PROFILE_RESEARCH_SUMMARY_ZH`: Chinese profile metadata
- `PROFILE_IMAGE`: profile image path; defaults to `assets/profile.png`
- `PROFILE_GOOGLE_SCHOLAR_URL`: Google Scholar profile URL
- `PROFILE_CV_PDF`: path to the English CV PDF; defaults to `assets/miao-jiong-tang-cv.pdf`
- `PROFILE_CV_PDF_ZH`: path to the Chinese CV PDF; defaults to `assets/tang-miaojiong-cv-zh.pdf`
- `GITHUB_TOKEN`: optional token for higher GitHub API rate limits
- `ORCID_ID`: ORCID iD used by `scripts/update_publications.py`
- `CROSSREF_EMAIL`: optional email for polite Crossref API requests
- `CROSSREF_QUERY_AUTHOR`: optional Crossref author query if ORCID is not configured
- `PUBLICATION_IMAGE_MIN_CONFIDENCE`: minimum image confidence for automatic publication image downloads; defaults to `medium`
- `PUBLICATION_PDF_MIN_CONFIDENCE`: minimum confidence for automatic publication PDF downloads; defaults to `medium`
- `PUBLICATION_PDF_TIMEOUT`: per-request timeout for PDF discovery; defaults to `15`
- `PUBLICATION_PDF_AUTO_DOWNLOAD`: set to `0` to disable automatic PDF downloads; defaults to downloading publicly discoverable PDFs
- `UNPAYWALL_EMAIL`: optional email for open-access PDF discovery through Unpaywall; falls back to `CROSSREF_EMAIL`

Publication updates read the public ORCID profile name and other names. Matching author names are
recorded in `data/publications.json` and underlined on generated publication pages.

Quarto reads generated files `_quarto.yml` and `_variables.yml`. Edit the template files
`_quarto.template.yml` and `_variables.template.yml` for structural changes, and use
environment variables for deployment-specific values.

If `ORCID_ID` or `PROFILE_ORCID` is configured and profile names are not set explicitly,
`scripts/configure_site.py` uses the public ORCID profile name and other names as fallbacks.
